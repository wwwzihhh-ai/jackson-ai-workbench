# Jackson 工作台 V1.3.1

Jackson 工作台是一个为手机和电脑设计的个人网页 App，把健身计划、财经新闻和今日待办放在同一个界面里。它不要求注册账号，个人资料默认只保存在当前浏览器中。

在线地址：<https://wwwzihhh-ai.github.io/jackson-ai-workbench/>

## 已经可以使用的功能

- 今日总览：查看本周训练进度、最新财经新闻和重要待办。
- 健身运动：胸、肩、背、胳膊、腿、核心、有氧七类训练，以及休息日。
- 一周安排：首次使用时自行设置周一至周日，每天只能选择一个部位或休息。
- 今日调整：可以临时换部位，也可以选择同步修改每周计划。
- 训练模板：新增、编辑、删除和排序动作；记录器械、重量、组数、次数、休息时间和备注。
- 训练过程：逐组打卡、组间倒计时、自动滚动、完成庆祝和连续打卡。
- 重量记忆：系统不再按体重估算公斤数；用户填写过的动作重量会在下次沿用。
- 体重照片日历：每天填写体重并上传一张照片，按月历回看，展示最新体重、较上次变化和最近 14 次趋势。
- 本地照片库：照片在当前设备压缩后存入 IndexedDB，不上传到 GitHub；训练完成弹窗可直接进入今日体重打卡。
- 财经资讯：通过 GDELT DOC 2.0 获取中文来源优先的 A 股、美股和宏观新闻，通常每约 30 分钟尝试更新。
- 今日待办：添加、编辑、完成、筛选和删除任务。
- 个性化：浅色、深色、跟随系统三种主题，侧边栏模块可长按排序。
- 侧栏折叠：点击侧栏分界按钮即可收起或展开；收起后内容铺满屏幕，并记住上次状态。
- 数据管理：本地数据可导入、导出和重置。
- PWA：可从 iPhone Safari 添加到主屏幕，支持核心页面离线回退。

## 使用的技术

项目使用原生 HTML、CSS 和 JavaScript，没有 React、Next.js 或 Vite，也没有第三方运行依赖。

```text
├─ index.html                      页面结构与 iOS/PWA 设置
├─ src/
│  ├─ styles.css                   响应式样式、深色模式和安全区域
│  └─ app.js                       工作台交互、体重照片库与旧数据迁移
├─ public/
│  ├─ news.json                    页面读取的财经新闻数据
│  ├─ manifest.webmanifest         PWA 应用信息
│  ├─ sw.js                        离线缓存与版本更新
│  └─ icons/                       主屏幕图标
├─ scripts/
│  ├─ fetch-news.mjs               GDELT 新闻抓取、校验和去重
│  ├─ check.mjs                    静态检查
│  ├─ test.mjs                     基础测试
│  └─ build.mjs                    生成 dist
└─ .github/workflows/deploy-pages.yml
                                     定时刷新新闻并部署 GitHub Pages
```

## 在本地运行

电脑需要 Node.js 20 或更高版本，以及 pnpm。

```bash
pnpm install
pnpm dev
```

终端会显示本地网址。常用质量检查命令：

```bash
pnpm check
pnpm test
pnpm build
```

如需手动尝试更新新闻：

```bash
pnpm news:update
```

这条命令需要访问 GDELT 网络服务。构建成功后的可部署文件在 `dist` 文件夹。

## GitHub Pages 部署与新闻更新

仓库已包含自动工作流。GitHub 仓库的 **Settings → Pages → Source** 需要设置为 **GitHub Actions**。

- 向 `main` 分支推送代码时会自动构建并更新网站。
- 工作流每小时第 17、47 分钟尝试更新一次新闻。
- 三个新闻分类按顺序请求并主动限速，数据会校验 HTTPS 链接、发布时间和标题重复。
- 定时抓取失败时，本次部署会停止，线上继续保留上一份成功数据。
- GitHub 定时任务可能有延迟。公开仓库连续约 60 天没有活动时，GitHub 可能暂停定时任务；到 **Actions → Deploy GitHub Pages → Run workflow** 手动运行一次即可恢复，并建议提交一次正常代码更新。

## 部署到 Vercel（可选）

1. 使用 GitHub 登录 Vercel。
2. 点击 **Add New → Project**。
3. 导入 `wwwzihhh-ai/jackson-ai-workbench`。
4. Framework Preset 选择 **Other**。
5. 构建命令使用 `pnpm run build`，输出目录使用 `dist`。
6. 点击 **Deploy**。

项目内的 `vercel.json` 已配置输出目录。需要注意：当前每 30 分钟的新闻自动刷新和部署是 GitHub Pages 工作流的一部分；Vercel 不会因为定时任务生成了临时文件而自动收到该文件。

## 环境变量

当前版本不需要环境变量或 API Key。GDELT DOC 2.0 的公开接口由 GitHub Actions 调用，网页里没有保存密钥。

`.env.example` 只保留说明，`.env`、`.env.local` 等文件均已加入 `.gitignore`。将来如接入需要密钥的服务，必须通过服务端和部署平台的环境变量保护，不能写入前端代码。

## 在 iPhone 添加到主屏幕

1. 使用 **Safari** 打开在线地址。
2. 点击 Safari 底部的 **分享** 按钮（方框向上箭头）。
3. 在菜单中向下找到 **添加到主屏幕**。
4. 名称保留为“Jackson 工作台”，点击右上角 **添加**。
5. 以后从桌面的 J 图标打开。

更新代码并部署后，主屏幕里的工作台仍使用同一个网址，会自动获得新版。Safari 或 PWA 可能短暂显示缓存版本，完全关闭后重新打开并联网一次即可更新。

## 数据升级和备份

V1.3.1 继续使用原来的本地存储标识 `jackson.ai.workbench.v1.1`，所以同一台 iPhone、同一个网站来源下，旧版的健身档案、正在进行的训练、完成组数、打卡日期、待办、主题和导航顺序都会保留。侧栏的展开或折叠状态也保存在当前设备。体重照片保存在同一网站来源的 IndexedDB 中；“导出备份”会把照片一并打包到 JSON，导入时可恢复。

代码更新不会删除本地数据，但以下情况会导致数据无法自动出现或被删除：

- 换手机、换浏览器或改用不同域名。
- 清除 Safari 的网站数据。
- 删除数据后没有备份。
- 在无痕浏览中使用。

建议定期进入右上角“数据管理”导出 JSON 备份。它目前没有账号和云端同步。

## 当前仍未真正实现的能力

- 新闻是约 30 分钟更新的准实时资讯，不是实时行情、交易数据或投资建议；首次抓取失败时会显示清楚标注的演示内容。
- 训练模板是通用参考，不是医疗建议，也不会根据伤病、动作能力或现场状态自动判断重量。
- 没有接入 Apple 健康、iCloud、系统通知或 Apple 提醒事项。
- 没有账号、云端数据库或跨设备自动同步。
- 体重照片和其他浏览器本地数据不会自动同步到另一台 iPhone，需要手动导出和导入。

## 数据与隐私

健身档案、体重照片、训练记录、待办和主题设置只保存在浏览器本地。新闻文件只包含公开文章的标题、来源、发布时间和原文链接，不上传个人资料。清除 Safari 网站数据会同时删除体重照片，操作前请先导出备份。
